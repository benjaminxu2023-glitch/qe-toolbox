About AQL sampling (ANSI/ASQ Z1.4 / ISO 2859-1)

Acceptance sampling by attributes lets you decide whether to accept a lot by inspecting only a sample of it. The procedure in three steps: (1) find the sample-size code letter from the lot size and inspection level (Table 1); (2) read the sample size n, acceptance number Ac and rejection number Re from the master table for your AQL (Table 2-A, normal inspection, single sampling); (3) inspect n units — accept the lot if defects ≤ Ac, reject if defects ≥ Re.

Arrow rules

When a table cell shows a downward arrow (↓), use the first available plan below it; an upward arrow (↑) means use the first available plan above. The calculator applies these automatically and tells you which code letter the plan was resolved from. If the sample size is greater than or equal to the lot size, the plan effectively requires 100% inspection.

Choosing an AQL

Common choices: 0.65%–1.0% for critical characteristics, 1.5%–2.5% for major, 4.0%–6.5% for minor. The AQL is a commercial agreement between supplier and customer, not a guarantee that a accepted lot is defect-free. Always confirm the AQL and inspection level in your quality agreement before use.

FAQ

Which standard does the calculator follow?

Single sampling, normal inspection, per ANSI/ASQ Z1.4-2003 (technically equivalent to ISO 2859-1). Table values were cross-verified against multiple published references; see the methodology note under the calculator.

Is the free calculator really free?

Yes — no account, no trial, no paywall. Pro ($19 one-time) adds Cpk/Ppk, 8D reports, GR&R and PDF export.

What does "resolved from code letter X" mean?

The master table uses arrows for cells where the nominal sample size is unsuitable; the plan is taken from the nearest suitable code letter. The calculator shows the resolution so the result is auditable.

Can I use this for regulated product (e.g. medical devices)?

The calculator is a planning aid. Your sampling rationale must be documented and approved under your own QMS; see the disclaimer.
